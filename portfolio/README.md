# portfolio

Daniel Muhoro's personal portfolio — a Next.js (App Router) site.

- **Live:** https://dmuhoro-portfolio.vercel.app
- **Vercel project:** `dmuhoro-portfolio` (Root Directory: `portfolio`)

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

See the [root README](../README.md) for monorepo structure, env vars, and architecture, and [DEPLOY.md](../DEPLOY.md) for the launch runbook.
